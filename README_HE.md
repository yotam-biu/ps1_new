# תרגיל 1 — Hello World

מטרת התרגיל: היכרות עם משתנים, מחרוזות וחיבור מחרוזות בפייתון.

יש לערוך את הקובץ `hello.py` כך שידפיס בדיוק `Hello World!` בשורה אחת.
בקובץ ההתחלתי חסרים רווח וסימן קריאה — זו המשימה שלכם.

**שנו רק את המחרוזת שמוצבת במשתנה `name` בשורה השנייה.** השאירו את שמות המשתנים ואת יתר הפקודות כפי שהם. אין להוסיף פקודת הדפסה נוספת.

רמז: חיבור מחרוזות באמצעות `+` אינו מוסיף רווחים או סימני פיסוק בעצמו.

## עבודה והגשה

- קבלו את ההזמנה לתרגיל ב־Classroom 50 ופתחו את המאגר האישי שנוצר עבורכם.
- פתחו את `hello.py`, לחצו על סמל העיפרון וערכו את השורה השנייה.
- שמרו באמצעות **Commit changes**.
- פתחו את **Actions**, בחרו **Autograding Tests** ובדקו את הריצה של השינוי האחרון.
- אם בדיקה נכשלת, קראו את המשוב, תקנו ושמרו שוב.

**ההגשה היא הקובץ `hello.py` שנשמר במאגר האישי שלכם.** המחברת היא לתרגול בלבד; שינוי במחברת לבדו אינו הגשה. פעלו גם לפי הנחיות המרצה לגבי מועד ההגשה.
